# 淘宝用户行为数据分析
> 电商用户行为EDA项目，使用 Python + Pandas + Matplotlib

## 📌 项目背景
基于淘宝公开用户行为抽样数据集，对用户浏览、收藏、加购、购买行为做探索性数据分析，统计PV、UV、漏斗转化率，分析用户活跃时段、热销类目、复购特征，输出业务优化建议。

## 🧾 字段说明
- user_id：用户ID
- item_id：商品ID
- category_id：类目ID
- behavior_type：行为类型（pv浏览，fav收藏，cart加购，buy购买）
- dt：行为日期
- hour：小时
- weekday：星期
- is_weekend：是否周末

## 📊 分析内容
- PV / UV 统计
- 漏斗转化率：浏览→收藏、浏览→加购、浏览→购买、加购→购买
- 用户时段活跃度分布
- 类目热度分布
- 用户复购情况分析

## 🔍 核心结论
1. 用户活跃高峰集中在午间 11:00–14:00，适合投放营销活动；
2. 加购后的购买转化率很高（92.81%），加购用户转化潜力强；
3. 成交高度集中在少数头部类目；
4. 用户以单次购买为主，高频复购忠实用户占比较低，复购留存是优化重点。

## 💡 运营建议
1. 优惠券、限时活动优先安排在午间流量高峰；
2. 重点运营头部爆款类目，搭配关联商品捆绑销售；
3. 对加购未下单用户做消息召回；
4. 针对已成交用户设计会员福利，提升复购率。
